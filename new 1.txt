Описание Генератора

Инструмент: tools/generator/generator.py
Назначение: Создание моделей для работы с данными.

2. Артефакты Генератора

Файл SQL:
Код для создания таблиц или представлений.
Включает запросы для выборки, агрегации и добавления столбцов.
Файл YML:
Метаданные модели.
Содержит имя, описание, теги, тесты и список колонок.

3. Режимы Работы Генератора

Режим создания модели (model):

На основе ручного описания таблицы в .yml файле
На основе физической таблицы в Greenplum
На основе записи в tech_etl.tables_meta


Режим создания источника (source):

На основе ручного описания таблицы в .yml файле
На основе физической внешней таблицы в Grenplum (external table)


4. Управление Файлами и Директория


Работа с данной инструкцией ведется из директории dbt_greenplum_elt/

Существующие файлы моделей .sql и .yaml не переписываются при повторном запуске generator.py, их необходимо удалить перед повторным запуском generator.py




Генерация моделей


1. Генерация источника данных



Создать источник в Greenplum


Открыть файл ..\tools\generator\configs\source_from_existing_table\source.yml
Структура файла:

source_name: dict_raw_ext # название источника в логике dbt (соответствует названию схемы источника)
schema: dict_raw_ext # название схемы источника
table: '"A003_READ"' # название таблицы-источника






Заполнить файл, подставляя актуальные значения
Запустить генерацию модели источника:

python ..\tools\generator\generator.py --mode source_from_existing_table --config source_from_existing_table/source.yml






2. Генерация DICT_STG-модели



Создать таблицу в Greenplum


Открыть файл ..\tools\generator\configs\model_from_existing_table\dict_stg.yml
Структура файла:

model:
  where_clause: 1 = 1 # условие фильтрации для источника dict_raw_ext."A003_READ" (опционально)
target:
  schema: dict_stg # название целевой схемы
  table: '"A003"' # название целевой таблицы
  distributed_by: replicated # распределение данных
  tags: ['DICT_LOADER'] # тег модели (соответствует названию сущности таблицы) 
source:
  source_type: source # тип источника
  source_name: dict_raw_ext # название схемы источника
  table: A003_READ # название таблицы-источника






Заполнить шаблон, подставляя актуальные значения
Запустить генерацию DICT_STG-модели:​

python ..\tools\generator\generator.py --mode model_from_existing_table --config model_from_existing_table\dict_stg.yml






Проверить созданную модель командой:

dbt run --select <название модели>





3. Генерация DICT_DDS-модели



Создать таблицу в Greenplum


Открыть файл ..\tools\generator\configs\model_from_existing_table\dict_dds.yml
Структура файла:

target:
  schema: dict_dds # название целевой схемы
  table: mandant # название целевой таблицы
  distributed_by: replicated # распределение данных
  tags: ['DICT_LOADER'] # тег модели (соответствует названию сущности таблицы)
source:
  query: | # блок select скрипта целевой таблицы (все строки должны быть отступлены минимум на один уровень относительно параметра query)
    SELECT 
    tech_etl.util_text_to_null_validation(t1."MANDT"),
    tech_etl.util_text_to_null_validation(t1."MWAER")
    FROM dict_stg."T000" t1;






Заполнить шаблон, подставляя актуальные значения
Запустить генерацию DICT_DDS-модели:​

python ..\tools\generator\generator.py --mode model_from_existing_table --config model_from_existing_table\dict_dds.yml






Проверить созданную модель командой:

dbt run --select <название модели>
