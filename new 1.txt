  Если вернёт список — пришли его, я подставлю точные названия категорий в скрипт.

  Также можно запросить все активности без фильтра категорий, если сервер позволяет:

  python3 - <<'PY'
  import os, requests
  base="https://yt.rusal.ru"
  headers={"Authorization":f"Bearer {os.environ['YOUTRACK_TOKEN']}", "Accept":"application/json"}
  url=f"{base}/api/issues/2-56109/activities"
  params={"fields":"author(name,login),timestamp,field(name),added(name),removed(name),to(name),target(customFields(name,value(name)))"}
  r=requests.get(url,headers=headers,params=params,verify=False)
  print(r.status_code, r.text[:2000])
  PY

  Если сервер всё равно отдаёт только комментарии/работы — значит историю статусов API не отдаёт на уровне сервера. Тогда вариант только через UI или админскую
  настройку.
