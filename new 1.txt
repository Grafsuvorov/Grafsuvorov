1. Пересобрать api из актуального кода:

  docker compose build --no-cache api
  docker compose up -d api

  2. Пересобрать frontend из актуального production env, чтобы он перестал бить в /h/auth/login:

  docker compose build --no-cache frontend
  docker compose up -d frontend

  Но сначала лучше выполнить 3 команды выше внутри API-контейнера.
  Они сразу покажут: маршрут вообще есть в запущенном приложении или нет.
