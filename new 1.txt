ocker compose exec api git --version

  Если ошибки — пересобираем с чисткой:

  docker compose build --no-cache api
  docker compose up -d --force-recreate

  И покажи лог сборки, особенно строку с apt-get install -y git.

  Также убедись, что ты реально правишь api/Dockerfile, а не другой файл.
  Можешь прислать sed -n '1,40p' api/Dockerfile — скажу, есть ли там блок с apt.
