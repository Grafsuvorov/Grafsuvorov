Описание

В рамках перехода расчётов всех направлений на dbt необходимо выполнять сверку результатов между текущей реализацией и новой реализацией на dbt.

Для автоматизации процесса разработана функция сравнения данных между двумя таблицами.

Перед использованием функции в рамках миграции требуется провести её функциональное тестирование и убедиться, что результаты сравнения являются корректными.

Цель

Провести валидацию функции сравнения данных:

проверить корректность работы функции на различных наборах данных;
убедиться, что функция корректно выявляет реальные расхождения;
проверить отсутствие ложных срабатываний;
протестировать различные сценарии использования;
выявить возможные ошибки, ограничения или некорректные результаты;
при необходимости подготовить предложения по доработке функции.
Описание функции
Входные параметры
схема и таблица №1;
схема и таблица №2.
Результат

Функция возвращает результат в формате JSON со следующими полями:

Поле	Описание
result	Общий результат сравнения (SUCCESS / ERROR) с пояснением причины
count_1	Количество строк в первой таблице
count_2	Количество строк во второй таблице
diff_count	Количество расхождений между таблицами
Логика проверки

Функция выполняет:

сравнение количества строк в таблицах;
сравнение содержимого всех бизнес-колонок;
системные поля (например, dt_insert, uuid и другие технические атрибуты) в сравнении не участвуют;
сравнение данных выполняется с использованием операций EXCEPT (или агрегированного сравнения, в зависимости от структуры таблицы);
формирование итогового заключения о наличии или отсутствии расхождений.
Ожидаемый результат

По итогам тестирования необходимо:

подтвердить корректность работы функции либо зафиксировать выявленные замечания;
описать сценарии, в которых функция работает некорректно (если такие будут обнаружены);
предоставить предложения по доработке логики сравнения (при необходимости).
