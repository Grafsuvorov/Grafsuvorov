500 на /api/table-variants
     Это не связано с YouTrack. Нужно посмотреть лог API контейнера.

  Команда на сервере:

  docker compose logs --tail=200 api

  И отдельно:

  curl -i http://localhost:5312/api/table-variants/ods/ral_rusal_sd2882m_7

  Чаще всего 500 тут из‑за:

  - проблемы с подключением к БД (DATABASE_URL)
  - SQL ошибка в запросе variants
  - таблицы нет/имена отличаются

  2. 404 на /api/click/meta/...
     Это нормально, если в CLICK_META_DIR нет мета для этих объектов.
     У тебя путь /app/config_files/meta — туда попадает meta из git.
     Если меты для ods/ral_rusal_sd2882m_7 или dm/sales_shipment_to_china_plan_vs_actual нет — будет 404.

  Проверь внутри контейнера:

  docker compose exec api /bin/sh -c "ls -la /app/config_files/meta/ods | head"
  docker compose exec api /bin/sh -c "ls -la /app/config_files/meta/dm | head"

  Если меты есть, но всё равно 404 — значит имена в метах другие (например _ral/_view). Тогда UI корректно показывает, что меты нет.
