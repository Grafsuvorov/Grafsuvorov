Проверить, что в prod-сборку фронта не подмешивается VITE_API_BASE_URL=h.
     На сервере в каталоге проекта выполни:

  grep -R "^VITE_API_BASE_URL" . .env* api/.env

  2. Пересобрать оба контейнера без кеша из актуального кода:

  docker compose build --no-cache frontend api
  docker compose up -d frontend api

  3. Проверить bundle после пересборки:

  docker exec -it table-dependency-viewer-frontend-1 sh -c "grep -R 'auth/login' /usr/share/nginx/html/assets | head"

  Там не должно быть "/h/auth/login" и не должно быть const ... = "h" для API base.

  4. Проверить API маршрут уже внутри контейнера одной строкой, без heredoc:

  docker exec -it table-dependency-viewer-api-1 sh -c "python -c 'from api.main import app; print([(r.path, sorted(r.methods)) for r in app.routes if \"/auth\" in
  r.path])'"

  Ожидаем:

  - во фронте запрос идет на /auth/login
  - в API есть ('/auth/login', ['POST'])
