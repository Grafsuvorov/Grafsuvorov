🎅 2. Код плагина (создай файл holiday_theme_plugin.py)
python
Копировать код
from airflow.plugins_manager import AirflowPlugin
from flask import Blueprint

holiday_bp = Blueprint(
    "holiday_theme",
    __name__,
    static_folder="static",
    static_url_path="/holiday_static",
)

class HolidayThemePlugin(AirflowPlugin):
    name = "holiday_theme"
    flask_blueprints = [holiday_bp]
Этот плагин подключит папку static/.

❄ 3. Добавим снег — файл snow.js
javascript
Копировать код
document.addEventListener("DOMContentLoaded", () => {
    const snow = document.createElement("div");
    snow.className = "snowflakes";
    document.body.appendChild(snow);

    for (let i = 0; i < 60; i++) {
        const flake = document.createElement("div");
        flake.className = "snowflake";
        flake.innerHTML = "❄";
        snow.appendChild(flake);
    }
});
