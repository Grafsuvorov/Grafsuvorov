то сделать:

  mkdir -p /var/lib/table-dependency-viewer/meta-workspaces

  Этого достаточно, если контейнеры у вас запускаются от root.

  Потом:

  git pull
  docker compose up -d --build api

  Что ещё важно:

  - ничего из проекта переносить не нужно
  - старые workspace вручную переносить не нужно
  - новая логика сама начнёт использовать:
      - /var/lib/table-dependency-viewer/meta-workspaces

  Если хотите проверить после старта:

  ls -la /var/lib/table-dependency-viewer/meta-workspaces
  docker compose exec api sh -lc 'echo $META_WORKSPACE_ROOT && ls -la $META_WORKSPACE_ROOT'

  То есть коротко:

  - создать директорию надо
  - переносить старые файлы не надо
  - проект из /root/... трогать не надо.
