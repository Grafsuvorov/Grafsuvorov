docker compose exec api sh -lc 'test -n "$GITLAB_TOKEN" && echo TOKEN_SET || echo TOKEN_EMPTY'

  Если увидите TOKEN_EMPTY, значит токен не попал в контейнер.

  Если токен есть, проверьте его вручную:

  curl --insecure --header "PRIVATE-TOKEN: <ВАШ_ТОКЕН>" "https://prod.gitlab.dwh.rusal.com/api/v4/projects/dwh%2Fetl"

  Если токен рабочий, должен прийти JSON проекта, не 401.

  Что нужно для токена в GitLab:

  - лучше создать Personal Access Token или Project Access Token
  - права минимум:
      - api
  - этого достаточно для создания merge request

  Где создать:

  - GitLab → ваш профиль → Access Tokens
    или
  - Project → Settings → Access Tokens

  Что поставить в compose:

  - GITLAB_TOKEN=ваш_реальный_токен

  После изменения:

  docker compose up -d --build api

  Потом проверить:

  docker compose exec api sh -lc 'test -n "$GITLAB_TOKEN" && echo TOKEN_SET || echo TOKEN_EMPTY'

  И ещё раз нажать Создать MR.
