✅ СКРИПТ №2 — Проверка invoice_realization + invoice_realization_position

Проблема №2: На PREPROD может быть другой набор документов, другой order или часть документов отсутствует.

-- Все документы реализации по активу
select 
    ir.invoice_realization_code,
    ir.dt_billing_document,
    irp.sales_document_code,
    irp.sales_document_position_code,
    irp.sales_document_position_type_code,
    irp.document_currency_vat_excluded_amount,
    irp.document_currency_code,
    irp.material_code
from dds.invoice_realization ir
left join dds.invoice_realization_position irp 
       on ir.invoice_realization_code = irp.invoice_realization_code
where substring(irp.material_code, 3) = '160000000136'   -- asset_main_code
order by ir.dt_billing_document desc, ir.invoice_realization_code desc;


👉 Сравни следующие поля между PROD и PREPROD:

sales_document_position_type_code должно быть ZAOS или ZAKT

document_currency_vat_excluded_amount

dt_billing_document

количество строк

сортировка (важно для row_number())

Если на PREPROD меньше строк → vbrk будет пуст.

✅ СКРИПТ №3 — Проверка sales_document_counterparty_role (роль VE)

Проблема №3: Контрагент с ролью VE может быть не загружен на PREPROD → buyer_code NULL.

Сначала получаем список документов:

-- получаем все sales_document_code
select distinct irp.sales_document_code
from dds.invoice_realization_position irp
where substring(irp.material_code, 3) = '160000000136';


Теперь подставляем список в следующий запрос:

-- Проверяем роль VE по документам
select 
    sales_document_code,
    sales_document_position_code,
    counterparty_role_code,
    counterparty_code
from dds.sales_document_counterparty_role
where sales_document_code IN ( <подставь список из предыдущего запроса> )
  and counterparty_role_code = 'VE';


👉 Если на PREPROD нет строки с role VE → buyer_code будет NULL.

🔍 СКРИПТ №4 — Вывести сам CTE vbrk (точечная проверка)

Это показывает, получает ли vbrk строку на PREPROD.

with vbrk as (
    select
        t.unit_balance_code,
        t.asset_main_code,
        t.payee_or_payer_code as buyer_code,
        t.personnel_code as realization_supervisor_code,
        t.document_currency_vat_excluded_amount as realization_document_currency_amount,
        t.document_currency_code as realization_document_currency_code
    from (
        select
            ir.payee_or_payer_code,
            irp.document_currency_vat_excluded_amount,
            irp.document_currency_code,
            sdcr.personnel_code,
            rf.unit_balance_code,
            substring(irp.material_code, 3) as asset_main_code,
            row_number() over (
                partition by irp.material_code  
                order by ir.invoice_realization_code desc,
                         ir.dt_billing_document desc
            ) as rnum
        from dds.invoice_realization ir
        left join dds.invoice_realization_position irp 
            on ir.invoice_realization_code = irp.invoice_realization_code
        left join dds.sales_document_counterparty_role sdcr 
            on sdcr.sales_document_code = irp.sales_document_code
           and (sdcr.sales_document_position_code = irp.sales_document_position_code
                or sdcr.sales_document_position_code = '000000')
           and sdcr.counterparty_role_code = 'VE'
        left join dict_dds.unit_balance rf 
            on rf.fixed_asset_material_prefix_code = left(irp.material_code, 2)
        where irp.sales_document_position_type_code in ('ZAOS','ZAKT')
    ) t
    where t.rnum = 1
)
select *
from vbrk
where unit_balance_code = '1520'
  and asset_main_code = '160000000136';


👉 Если на PREPROD результат пустой — 100% причина найдена.
