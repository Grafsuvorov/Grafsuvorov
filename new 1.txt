Со стороны DE предлагаем:

На слое ODS производить очистку, но не сохранять как null (нормализация данных)
Для текстовых полей если пробелы - приводить к пустой строке
Для дат если дата как пустая строка или "00000000" или !~ '^\d{8}$', то сохраняем как to_date('19000102', 'YYYYMMDD')
Для дат если дата < '19000101' то сохраняем как to_date('19000101', 'YYYYMMDD')
Для дат если дата >= '22991231' то сохраняем как return to_date('22991231', 'YYYYMMDD')
В слоях dds и dm - получаем меньше редистрибуций из-за отсутствия необходимость соединять таблицы по ключевым полям через функции coalesce
В слое dm_view в представлениях для каждого поля автоматически применяется функция автоматической замены на null
Такое правило нормализации данных позволит использовать единообразные фильтры для полей
Другими словами, предлагаем замену на null перенести с начала пайплайна (ods слоя) в конец пайплайна (dm_view слой)
