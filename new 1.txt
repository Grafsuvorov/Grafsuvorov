docker run --rm table-dependency-viewer_frontend sh -c "grep -n 'pid' /etc/nginx/nginx.conf && sed -n '1,20p' /etc/nginx/nginx.conf"

  Если там всё ещё:

  pid /run/nginx.pid;

  значит sed в Dockerfile не зацепил реальную строку.

  Тогда самый надёжный фикс такой:

  - не патчить системный nginx.conf через sed
  - а положить свой nginx.conf целиком

  Нужно будет сделать так в репозитории:

  - добавить свой nginx-main.conf с:

  user nginx;
  worker_processes auto;
  pid /tmp/nginx.pid;

  events {
      worker_connections 1024;
  }

  http {
      include /etc/nginx/mime.types;
      default_type application/octet-stream;
      sendfile on;
      keepalive_timeout 65;
      include /etc/nginx/conf.d/*.conf;
  }

  И в Dockerfile:

  FROM nginx:alpine
  COPY nginx-main.conf /etc/nginx/nginx.conf
  COPY nginx.conf /etc/nginx/conf.d/default.conf
  COPY --from=build /app/dist /usr/share/nginx/html
  EXPOSE 80
  CMD ["nginx", "-g", "daemon off;"]

  Но сначала лучше проверить текущий образ этой командой.
  Пришлите вывод grep -n 'pid' /etc/nginx/nginx.conf, и я дам уже точную правку без лишних попыток.
