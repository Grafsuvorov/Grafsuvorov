 df -h
  docker system df

  Что обычно помогает:

  docker builder prune -af
  docker image prune -af
  docker container prune -f
  docker volume prune -f

  Если нужно почистить всё агрессивно:

  docker system prune -af --volumes

  Но это удалит:

  - неиспользуемые образы
  - stopped containers
  - build cache
  - dangling volumes

  Если на сервере крутятся другие проекты, сначала лучше посмотреть:

  docker system df -v

  По api/Dockerfile у вас всё нормально:

  - там обычный apt-get update && apt-get install ...
  - он падает не из-за команды, а потому что Docker некуда писать

  После очистки:

  docker compose build --no-cache api frontend
  docker compose up -d

  Если хотите, могу сразу дать вам безопасную последовательность команд очистки именно для прод-сервера, чтобы не снести лишнее.
