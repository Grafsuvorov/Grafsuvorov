3. Проверить, что контейнер видит эти env:

  docker exec -it table-dependency-viewer-api-1 sh -c 'env | grep AIRFLOW_DEV'

  После этого кнопка Запустить DEV DAG должна начать ходить в Airflow.

  Еще полезно:
  в Swagger попробуй руками именно trigger:

  - POST /api/v1/dags/{dag_id}/dagRuns

  Для dag_id бери имя файла без .yaml, например:

  - dict_dds_currency_rates_meta.yaml
  - dag_id = dict_dds_currency_rates_meta

  Body можно такой:

  {
    "conf": {
      "schema_name": "dm",
      "file_name": "dict_dds_currency_rates_meta.yaml",
      "remote_path": "/home/airflow/config_files/meta/dm/dict_dds_currency_rates_meta.yaml",
      "author": "Nikita.Suvorov@rusal.com",
      "dev_bypass_dm_sensor": true
    }
  }

  Если в Swagger этот POST проходит, приложение тоже заработает с теми же кредами.

  Важно:

  - даже после успешного trigger dm_sensor сам не станет зеленым, если DAG на стороне Airflow не читает dev_bypass_dm_sensor.
  - это нужно доделать в самом DAG.

  Если хочешь, следующим сообщением я дам тебе точный тестовый POST для Swagger по любому твоему файлу.
