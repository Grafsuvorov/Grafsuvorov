 Вот готовый вариант:

  #!/usr/bin/bash
  set -euo pipefail

  unset http_proxy
  unset HTTPS_PROXY
  unset https_proxy
  unset HTTP_PROXY

  echo 'gogogogo'
  cd "/root/git_dir/etl"
  git pull

  cd /root/table-dependency-viewer/

  # meta_info (как было)
  rsync -atv --delete /root/git_dir/etl/meta_info/ /root/table-dependency-viewer/meta_info/

  # config_files/meta (новое)
  mkdir -p /root/table-dependency-viewer/config_files
  rsync -atv --delete /root/git_dir/etl/config_files/ /root/table-dependency-viewer/config_files/

  echo 'Закончили упражнение'
  echo 'Как же ты хорош!'

  Важно:

  - Если у тебя в репе лежит только config_files/meta, то путь будет такой же: /root/git_dir/etl/config_files/...
  - Если только meta без config_files, скажи — подстрою.

  После правки не забудь сделать:

  chmod +x /root/table-dependency-viewer/scripts/ci_cd.sh

  Если хочешь, добавлю лог ротацию или запись в файл.
